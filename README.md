# Entre Páginas

Biblioteca digital para leitura online de livros, contos, histórias e textos.

## Primeira versão
- Página inicial responsiva
- Biblioteca com capas
- Leitor de capítulos
- Modo claro/escuro
- Controle de tamanho da fonte
- Estrutura simples, sem banco de dados
- Pronto para publicação no Netlify

4. Progresso de leitura
